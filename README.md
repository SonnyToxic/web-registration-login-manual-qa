# Web Registration & Login — Manual QA Testing

## Project Overview

This is a demo QA portfolio project focused on manual testing of web registration and login functionality.

The project demonstrates practical skills in:

- Test case design
- Functional testing
- Positive and negative testing
- Boundary value testing
- Checklist creation
- Bug identification
- Bug reporting
- Test execution and result analysis

> **Note:** This is a demo QA project created for portfolio purposes. Test execution results are simulated for learning purposes and do not represent testing of a real commercial product.

---

## Testing Objective

The goal of this project is to verify that registration and login functionality works according to the defined requirements and handles invalid user input correctly.

---

## Requirements

### Registration

1. Email is required.
2. Password is required.
3. Password must contain at least 8 characters.
4. Confirm Password is required.
5. Password and Confirm Password must match.
6. Successful registration redirects the user to the Account Page.

### Login

7. Email is required.
8. Password is required.
9. Valid credentials allow the user to log in.
10. Invalid credentials should not allow the user to log in.
